# PicoBoy

A **GameBoy-inspired game and application launcher built from the ground up for the Raspberry Pi Pico**.

Designed around a **3.5" 320×480 ILI9486 display**, PicoBoy is a personal hardware project combining embedded programming, graphics, and game development into a small handheld-style system.

The project is **open source under the MIT License** and is continuously evolving as new features, games, and experiments are added.

Built by **Kaaren Mesbah (SandFood)**.
